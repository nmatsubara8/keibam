# 卍さん式 馬券戦略ノート

スライドから抽出・整理した、得点付け・ファクター選定・馬券の買い方に関するメモ。

---

## 1. 各馬に点数を付ける

過去実績や近走内容をもとに、各馬へ加点・減点していく。

- 過去に同一レースに出走していて、着順が良かったほうの馬に **−1点**、着順が悪かった方に **+1点**
- 近走で、出遅れたことがある馬は **+1点**
- 近走で、道中で不利を受けたレースがある馬は **+1点**
- 近走で、勝ち馬から0.5秒以内なら **+1点**、0.2秒差以内ならさらに **+1点**
- 今走が芝の場合、近走（過去5走）でダートで好走している馬は **−1点**、凡走している馬は **+1点**
- 今走が良馬場の場合、近走で不良馬場で好走している馬は **−1点**、凡走している馬は **+1点**
- etc…

## 2. 得点のファクター（考え方）

- 過去データを分析し、さまざまなファクターについて、回収率面で優位な傾向があるかどうかを検証する
- 「前走着順」「血統」「騎手」「枠順」「負担重量」など、ファクターは多様
- 分析の際、的中率は無視し、**回収率のみに着目**する
- 仮説を立て回収率を分析し、明確あるいは普遍的な傾向があるかどうかで判断する
- 信頼度の低いファクターは排除し、**信頼度の高いファクターのみを採用**する
- ファクターはできるだけ多い方が良い

## 6. 買い目のゾーン

指数（得点）とオッズの2軸マトリクスで、買う／買わないを切り分ける。

- **横軸（→右）**：指数（得点）が高い
- **縦軸（↑上）**：オッズが高い（＝配当が高い／人気薄）

中央の帯（指数もオッズも“そこそこ”の中庸ゾーン）だけを買い、周囲は見送る。

### 買うゾーン

- 指数そこそこ … 極端に高くも低くもない、中〜上位の得点
- オッズもそこそこ … 人気すぎず（配当が低すぎず）、人気薄すぎず（高配当すぎず）

→ 実力（指数）と妙味（オッズ）のバランスが取れた、期待値が乗りやすい領域だけを買う。

### 買わないゾーン

| ゾーン | 位置 | 理由 |
|---|---|---|
| 低指数ゾーン（そもそも指数が低い） | 左端の列 | 得点が低く、実力評価が足りない |
| 低配当ゾーン（配当が低すぎる） | 下段中央 | オッズが低すぎて妙味・期待値が乗らない |
| 高指数・低配当ゾーン | 右下 | 指数は高いが人気になりすぎて配当が見合わない |
| 高指数・高配当ゾーン | 右上 | 指数トップ級なのに異常に人気薄＝嫌われる要因の可能性（危険） |
| 高指数過ぎるゾーン（高配当過ぎる） | 上段中央 | 配当が高すぎて波乱狙いになり、的中が安定しない |

※ 四隅の小マス「低指数・高配当」「低指数・低配当」も、指数が低い時点で対象外。

### まとめ

> 指数（実力）とオッズ（配当妙味）の両方が“中庸〜そこそこ”に収まる馬だけを買い、どちらかが極端に振れたら見送る。

- 人気すぎ（配当が低すぎ）→ 妙味なしで見送り
- 人気薄すぎ（配当が高すぎ）→ 的中率が落ちるので見送り
- 指数が低い → 実力不足で見送り
