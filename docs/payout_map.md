# 荒れ度×配当 と bold-play の数値地図（中央 JRA / 地方 NAR）

## 問い

「常勝＝プラス収支」ではなく、**(a) どの条件で高配当が出やすいか**、**(b) 一撃（高額馬券）狙いの
的中率・配当分布はどうなるか**を数値化する。edge は主張しない。

## 方法

- netkeiba から中央250レース・地方475レースの単勝/着順＋三連単払戻を取得（`scripts/payout_map/`）。
- 荒れ度 = 単勝含意勝率 p_i の正規化エントロピー Hn = −Σp_i ln p_i / ln(頭数) ∈ [0,1]（0=断然人気、1=均等）。
- bold-play の目標到達確率は順序ブートストラップ（¥100単位・順序ランダム化）。

## (a) 荒れ度 → 三連単配当（両プールで成立、JRAは桁が大きい）

| | corr(Hn,log配当) | 配当中央値（堅い→荒れ） | 本命的中率（堅い→荒れ） |
|---|---|---|---|
| 中央(JRA) | 0.310 | ¥10,980 → ¥70,890 | 4.0% → 2.0% |
| 地方(NAR) | 0.390 | ¥4,600 → ¥28,070 | 10.5% → 0.0% |

荒れる（断然人気なし）ほど配当は単調に跳ね、本命的中率は落ちる。**両方とも市場に織り込み済み**
（だから配当が大きい）＝「荒れる条件」は予測できても +EV にならない。JRA は多頭数・大プールで
**配当スケールが中央値で2〜3倍大きい**（90%点は最大¥47万）。

## (b) ターゲット別の的中率・回収率・配当分布（各レース定額）

| 戦略 | JRA 的中/回収 | NAR 的中/回収 |
|---|---|---|
| 本命1点(1>2>3) | 3.6% / 1.08※ | 4.7% / 0.54 |
| 上位3頭BOX(6点) | 12.4% / 0.94 | 13.6% / 0.57 |
| フォーメーション1→234→234 | 9.2% / 0.57 | 18.3% / 0.82 |
| 中穴(4>5>6) 1点 | 0.0% / 0.00 | 0.0% / 0.00 |
| 大穴(下位3頭) 1点 | 0.0% / 0.00 | 0.0% / 0.00 |

※ JRA 本命1.08 は的中約9回（250R×3.6%）の**小標本ノイズ**で +EV の証拠ではない（損益分岐近傍）。

- **深い穴の狙い撃ちは中央250R・地方470Rとも的中0回** — 特定の万馬券を"予想して当てる"のは不可能。
- **≥100倍の大当たりは BOX/フォーメーション**（そこそこの上位馬を手広く押さえ想定外の着順を拾う）から
  数回出る。深い穴からは出ない。
- **全戦略で回収率<1.0（平均マイナス）**。本命=高的中・低配当、穴=低的中・高配当で、予測の勝敗でなく
  「分布の形」を選んでいるだけ。

## bold-play（賭け金額の大胆さ）：両プールで理論通り、JRAの方が届きやすい

「¥1万→¥5万（5倍）到達確率」（同じ買い目・stake の攻め方だけ変える）:

| 戦略 × stake | 中央(JRA) | 地方(NAR) |
|---|---|---|
| 本命1点 × timid(2%) | 0.9% | 0.0% |
| 本命1点 × **bold(50%)** | **7.8%** | 4.0% |
| 上位3頭BOX × bold(50%) | 9.8% | 3.6% |
| 大穴 × bold(50%) | 0.0% | 0.0% |

**同じ買い目でも stake を timid→bold にするだけで到達確率が跳ねる**（Dubins–Savage の bold play）。
JRA の方が高い（配当が大きい＝5倍に届きやすい）。ただし「大穴×bold」は的中ほぼ0で両プール0%＝
**一撃の器は深い穴でなく本命/BOX への大胆な賭け金**。そして EV は常にマイナス。

## 結論

- **(a) 荒れ度は配当を強く予測できるが織り込み済で edge にならない**（JRA は舞台が派手）。
- **(b) どのターゲットも平均マイナス**。深い穴の狙い撃ちは中央でも的中0。予測の勝敗でなく分布の形を
  選んでいるだけ。
- **一撃狙いなら bold play**（本命/BOX を大胆 staking）が両プールで機能し JRA の方が届きやすいが、
  それは**負けを承知で分散を買う設計**であって予測の勝利ではない。損失最小化の真逆の目的関数。

## 再現手順

`scripts/payout_map/`（データは第三者由来・ephemeral ゆえ非コミット。`data/` は gitignore）:

```
python scripts/payout_map/scrape_pool.py --pool jra --n-races 250 --out data/payout_map/jra
python scripts/payout_map/scrape_pool.py --pool nar --n-races 250 --out data/payout_map/nar
python scripts/payout_map/analyze_payout_map.py --label 中央(JRA) \
    --runners data/payout_map/jra_runners.csv --payoffs data/payout_map/jra_payoffs.csv
python scripts/payout_map/analyze_payout_map.py --label 地方(NAR) \
    --runners data/payout_map/nar_runners.csv --payoffs data/payout_map/nar_payoffs.csv
```
