# Markov / 深層RL 手法の競馬無効性の実証

## 主張（no-free-information 定理）

**効率的なパリミュチュエル（pari-mutuel）市場では、強化学習（RL）も隠れマルコフ
（HMM/Markov）によるレジーム検出も、市場を破れない。**

理由は単純で、これらの手法は「方策」や「レジームの推定」を最適化するが、**状態（観測）に
存在しない情報を新しく作り出すことはできない**。パリミュチュエルではオッズ＝市場参加者の
総意の集約であり、市場が効率的なら「まだ価格に織り込まれていない構造」は残っていない。

したがって、任意のベットの単位あたり期待純損益は

```
E[純損益] = 的中確率 × オッズ − 1 = (1 − 控除率) − 1 = −控除率  < 0
```

に収束する。一方「賭けない（abstain）」の報酬は常に 0。**0 > −控除率** なので、RL が
学習しうる最適方策は **abstain（賭けない）** である。「打つ手が無い」のではなく、
**最適な打ち手が『打たないこと』** になる。

レジームが実在しても結論は変わらない。市場がそのレジームを価格に織り込む（効率的オッズ）
限り、レジームを正しく当てても払戻に反映済みなので、依然として控除率ぶん負ける。マルコフ/
HMM の時系列フィルタが価値を持つのは、市場がレジームを**まだ織り込んでいない**（＝非効率・
stale なオッズ）ときだけ。これが Benter が香港の低効率プールで、Ranogajec がリベートで
edge を得た構図であり、**公開 JRA 単勝データ（echo≈0.989, ΔR²≈0 の効率的市場）では成立
しない**。

## 実証装置

`src/simulation/_efficient_market.py`（純 numpy・seed 制御・hmmlearn 非依存）。

### 市場シミュレータ

潜在レジーム `z ∈ {0,1}` を 2 状態マルコフ連鎖で回し、レジーム=1 のとき「優遇集合」の馬に
強さボーナスを与える。オッズは `odds = (1 − 控除率) / p_market` で決まり、**市場が
レジームを織り込むか否か**を 2 モードで切り替える:

| モード | p_market | 意味 |
|---|---|---|
| `MODE_EFFICIENT` | `p_true`（レジーム込み） | 効率市場。公開 JRA 単勝（echo≈0.989）に対応 |
| `MODE_STALE` | レジーム無視の素の強さ | 非効率市場。対照群。Benter の香港プール相当 |

効率市場では `p_market·odds = 1 − 控除率` が**全馬で厳密に成立**（どの馬に賭けても EV 同一
＝控除率ぶん負ける）。stale 市場ではレジーム=1 の優遇馬で `p_true > p_market` となり、
`p_true·odds > 1`（正の期待値）の馬が生まれる＝**市場が価格に織り込み損ねた情報**。

### 3 つのエージェント

1. **市場ベースライン**（`market_baseline`）— 本命を毎レース買う。効率市場での平均純損益は
   厳密に −控除率（＝素朴参加は控除率ぶんの損）。
2. **文脈付きバンディット / 表形式 Q 学習**（`ContextualBandit`）— 完全フィードバック
   （競馬は発走後に全馬の着順が判明 → 各行動の反実仮想払戻も計算可能）でサンプル平均 Q を
   推定。行動 = {賭けない, 本命, レジーム本命}。状態 = (レジーム事後 bin, **偽の文脈** noise bin)。
   貪欲方策はどの賭けの Q も 0 未満なら abstain を選ぶ。
3. **HMM レジーム戦略**（`regime_strategy`）— 2 状態ガウス HMM の前向きフィルタで
   `P(z=1 | 観測)` を推定し、閾値超のレースだけレジーム本命を買う。

## 結果（`python verify_rl_markov_futility.py`, seed=0, 控除率20%）

| 戦略 | 効率市場（公開 JRA 相当） | stale 市場（非効率・対照群） |
|---|---|---|
| 素朴ベット（本命） | 純損益 **−21%**（≈ −控除率） | −24% |
| RL 粗い文脈 OOS | **96% 見送り**・純損益 −0.8%（**利益ゼロ**） | +26%（真の edge を掴む） |
| RL 細かい偽文脈 in-sample | **+24%**（見かけの利益） | +56% |
| RL 細かい偽文脈 OOS | **−30%**（消滅） | +25% |
| HMM レジーム戦略 OOS | **−25%**（レジームは価格済み） | **+53%** |

読み取り:

1. **効率市場では『賭けない』が最適** — RL（粗い文脈）は OOS で 96% のレースを見送り、
   利益ゼロ。状態に無い情報は作れない。最適方策は abstain。
2. **『回収率300%』は文脈/閾値の切り過ぎ（過学習）で作れるが OOS で消える** — 偽文脈を
   40 分割すると in-sample は +24%、OOS は −30%。動画の300%と同じ機序（test 上での買い目
   閾値の後付け最適化＝多重比較）。過学習の強さは「文脈の細かさ（モデル複雑度）」の関数。
3. **無効性の原因はアルゴリズムでなく市場効率** — 同じ HMM レジーム戦略が、効率市場
   −25% → stale 市場 +53% と反転して勝つ。同じ RL も −0.8% → +26%。**edge は
   『市場がまだ価格に織り込んでいない情報』からのみ生まれる。**

## なぜ金融市場のレジーム/RL 手法が競馬に移らないか

- 金融のレジームスイッチング（HMM）や RL 執行が機能するのは、価格が**逐次的**に動き、
  約定・板・遅延に**摩擦（＝非効率）**が残るから。競馬の単勝は発走時に一括確定する
  パリミュチュエルで、締切時のオッズが全情報を集約し、レース同士はほぼ独立。時系列で
  「持ち越せる非効率」が構造的に乏しい。
- 実データでの傍証: `verify_dynamics_vs_harville.py` — 無料データ由来の展開/当日バイアス
  特徴が Harville 複勝残差を説明する力は **R²≈0.0001**。レジーム的な残差構造は市場（単勝
  オッズ）に既に織り込まれており、検出しても賭けに変換できない。

## リポジトリ内の位置づけ

- 予測エッジの探索は公開データでは NO-GO（本文書＋`docs/loss_minimization_design.md`＋
  `.claude-context.md` の35年データ/元ネタ動画685ノート解析）。
- したがって合理的な最適化は「利益の最大化」ではなく **損失の最小化**
  （`src/policies/_loss_minimization.py`）。本文書はその前提（＝高度な学習手法でも壁は
  崩れない）を、RL/Markov について自己完結の対照実験で固める。
