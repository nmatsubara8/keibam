LightGBMのようなモデルはハイパーパラメータ数が非常に多く、Hyperoptを用いた場合、100回〜200回程度の探索が必要となり、計算時間がかかります。

1.  **計算リソースの確保**: 開発や実験時には、自前の計算サーバーやGCE（Google Cloud Engine）を利用します。
2.  **コスト最適化**: GCEの計算余剰リソースを利用できる**プリエンティブルインスタンス**の活用が推奨されます（約70%オフ）。
3.  **リスク対策**: プリエンティブルインスタンスは予告なく停止するリスク（最大24時間という制約あり）があるため、**Hyperoptの探索中間状態（`Trials`オブジェクト）を定期的にピクル化して保存**することが極めて重要です。これにより、インスタンスが切断されても途中から再開できます。
